# Brickhold website direction

The 2026-11-26 redesign replaces the initial studio/editorial layout with a game-first presentation. The user supplied three references: [Aggro Crab](https://aggrocrab.com/), [PEAK](https://peakpeakpeak.com/), and their own earlier [Tidy Tides](https://www.tidytides.co.za/) website. These were reviewed in a real browser before implementation.

Tidy Tides supplies the main direction: a full-screen game environment, expressive type and a page that shares the game's theme. PEAK reinforces the value of a large game title, sparse navigation and artwork that fills the opening viewport. Aggro Crab supplies permission for deliberate oddness and short, playful copy. Their logos, artwork, layouts and CSS were not copied.

Brickhold's palette comes from its existing castle/portal artwork: gold, portal purple, parchment and a soft garden green. Bungee provides chunky display lettering. The game wordmark adds original CSS brick studs, outline and dimensional shadows. The shell's navigation sits over the opening scene and gains a solid background on scroll. Castle battlements connect sections; artwork sits in an angled print-like frame; the field guide uses illustrated collectible cards; contact uses a raven-stamped postcard.

Only original code-drawn decorations and existing Brickhold artwork are used. Concept images remain labelled as concept artwork. The engine screenshot is labelled prototype gameplay. There is no invented trailer, Steam link, release date, team roster or public playtest. The studio email remains the contact action.

The four independently built React sections and optional local BFF are preserved. Pointer movement creates only a small change in the opening scene's position, and reduced-motion preferences disable it. Navigation, field-guide filters, dialogs and contact actions remain keyboard accessible. The production artifact is checked at domain root and beneath a GitHub Pages repository path.
